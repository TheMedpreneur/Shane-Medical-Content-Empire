# Scripts

Educational scripts and storyboards for medical content production.

## Script Types

### Educational Scripts
- **Lecture Scripts**: Structured presentations with key learning points
- **Narration Scripts**: Voiceover for visual content
- **Discussion Scripts**: Interactive dialogue formats
- **Case Study Scripts**: Patient scenario presentations

### Procedural Scripts
- **Surgical Procedures**: Step-by-step surgical technique narration
- **Clinical Skills**: Physical examination and clinical procedures
- **Laboratory Techniques**: Lab skills and protocols
- **Emergency Procedures**: Time-critical interventions

### Assessment Scripts
- **Quiz Questions**: Multiple choice, true/false, matching
- **OSCE Scenarios**: Standardized patient encounters
- **Case-Based Questions**: Clinical reasoning assessments
- **Practical Skills**: Hands-on competency evaluations

## Script Format

### Standard Template
```
TITLE: [Procedure/Topic Name]
DURATION: [Estimated length]
TARGET AUDIENCE: [Medical students, residents, etc.]
LEARNING OBJECTIVES:
- Objective 1
- Objective 2

SCRIPT:
[Scene 1]
VISUAL: [Description of what appears on screen]
AUDIO: [Narration text]

[Scene 2]
...
```

## Medical Accuracy

All scripts must:
- Be reviewed by qualified medical professionals
- Reference current medical standards
- Include appropriate disclaimers
- Use accurate medical terminology
- Cite evidence-based sources

## Script Development Process

1. **Research**: Gather medical information and evidence
2. **Outline**: Structure content logically
3. **Draft**: Write initial script version
4. **Review**: Medical expert validation
5. **Revise**: Incorporate feedback
6. **Final Review**: Quality assurance
7. **Approval**: Sign-off for production

## Style Guidelines

- Use clear, concise language
- Define medical terms on first use
- Write for the target audience level
- Maintain professional tone
- Include pronunciation guides for complex terms
- Use active voice when possible

## Voiceover Guidelines

### Delivery
- Professional, authoritative tone
- Clear enunciation
- Appropriate pacing (not too fast or slow)
- Natural inflection
- Emphasis on key points

### Technical Requirements
- High-quality recording environment
- Professional microphone
- Noise reduction
- Audio normalization
- Consistent volume levels

## Storyboarding

Visual planning for complex procedures:
- Sketch key scenes
- Note camera angles
- Identify graphics needs
- Plan transitions
- Mark timing cues

## Version Control

- Use semantic versioning (v1.0.0)
- Track all changes with dates
- Note reviewers and approvers
- Maintain revision history
- Archive old versions

## Collaboration

- Use collaborative editing tools
- Track comments and suggestions
- Assign sections to subject matter experts
- Regular review meetings
- Final sign-off process
