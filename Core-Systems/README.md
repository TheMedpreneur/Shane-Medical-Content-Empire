# Core-Systems

This directory contains the core technical systems for the medical education content creation platform.

## Structure

### UE5-Project
- Unreal Engine 5 project files
- Medical anatomy visualization scenes
- 3D medical models and assets
- Animation blueprints for medical procedures
- Integration with medical anatomy packs

### Ludus-AI-Blueprints
- Ludus AI integration blueprints
- AI-driven content generation systems
- Procedural medical scenario generation
- Interactive learning modules powered by AI

### Cursor-AI-Code
- Cursor AI code implementations
- AI-assisted code generation
- Automation scripts
- Integration utilities

## Getting Started

1. Install Unreal Engine 5 (latest stable version)
2. Install required medical anatomy packs
3. Configure Ludus AI and Cursor AI integrations
4. See Documentation/Setup-Guides for detailed setup instructions

## Requirements

- Unreal Engine 5.3+
- Ludus AI plugin
- Cursor AI extension
- Medical Anatomy Pack (licensed)
- High-performance workstation (see system requirements in Documentation)
