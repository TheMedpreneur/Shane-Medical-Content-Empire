# Assessments

Evaluation tools for measuring medical education learning outcomes.

## Assessment Types

### Formative Assessments
- **Knowledge Checks**: Quick quizzes during learning
- **Self-Assessments**: Learner self-evaluation tools
- **Practice Questions**: Low-stakes practice opportunities
- **Peer Review**: Collaborative evaluation
- **Reflection Activities**: Critical thinking exercises

### Summative Assessments
- **Module Exams**: Comprehensive knowledge tests
- **Skills Demonstrations**: Practical competency evaluations
- **OSCE Stations**: Objective Structured Clinical Examinations
- **Portfolio Reviews**: Cumulative work assessment
- **Final Examinations**: Course completion assessments

## Question Types

### Multiple Choice Questions (MCQ)
- Single best answer
- Multiple correct answers
- Clinical vignettes
- Extended matching questions
- Evidence-based medicine questions

### Practical Assessments
- **Procedural Skills**: Step-by-step procedure evaluation
- **Physical Examination**: Clinical examination checklists
- **Communication Skills**: Patient interaction assessment
- **Diagnostic Reasoning**: Clinical decision-making
- **Emergency Management**: Time-critical scenarios

### Written Assessments
- Short answer questions
- Essay questions
- Case analysis
- Literature review
- Research proposals

### Performance-Based
- Simulation scenarios
- Virtual patient encounters
- 3D anatomy identification
- Procedure technique evaluation
- Team-based exercises

## Assessment Design Principles

### Validity
- **Content Validity**: Covers learning objectives
- **Construct Validity**: Measures intended competency
- **Criterion Validity**: Predicts performance
- **Face Validity**: Appears relevant to learners

### Reliability
- **Internal Consistency**: Questions measure same construct
- **Inter-Rater Reliability**: Consistent scoring between evaluators
- **Test-Retest Reliability**: Stable results over time
- **Standard Setting**: Appropriate difficulty levels

### Fairness
- Unbiased questions
- Accessible to all learners
- Clear instructions
- Reasonable time limits
- Appropriate accommodations

## Question Bank Structure

```
QUESTION ID: [Unique identifier]
TYPE: [MCQ/SAQ/Practical]
TOPIC: [Medical specialty/system]
DIFFICULTY: [Easy/Medium/Hard]
BLOOM'S LEVEL: [Knowledge/Comprehension/Application/Analysis]
ACGME COMPETENCY: [Patient Care/Medical Knowledge/etc.]

QUESTION STEM:
[Question text with clinical vignette if applicable]

OPTIONS: (for MCQ)
A. [Option text]
B. [Option text]
C. [Option text]
D. [Option text]
E. [Option text]

CORRECT ANSWER: [Letter or detailed response]

RATIONALE:
[Explanation of correct answer]
[Explanation of why other options are incorrect]

REFERENCES:
[Citations to medical literature]

METADATA:
- Keywords: [Tags for categorization]
- Usage Count: [Times used]
- Performance: [% correct]
- Last Updated: [Date]
```

## OSCE (Objective Structured Clinical Examination)

### Station Components
- **Scenario Brief**: Patient case details
- **Task Instructions**: What learner must do
- **Standardized Patient**: Trained actor or simulated patient
- **Checklist**: Observable behaviors and skills
- **Time Limit**: Typically 5-15 minutes
- **Examiner Guide**: Scoring instructions

### Common OSCE Stations
- History taking
- Physical examination
- Procedural skills
- Communication (breaking bad news, consent)
- Diagnostic interpretation
- Management planning
- Professional behavior

## Adaptive Assessments

Using AI to personalize assessments:
- Adjust difficulty based on performance
- Focus on weak areas
- Reduce redundancy
- Optimize testing efficiency
- Provide targeted feedback

## Feedback and Remediation

### Immediate Feedback
- Correct/incorrect indication
- Rationale explanations
- Links to review content
- Performance metrics
- Progress tracking

### Detailed Feedback
- Strength areas identified
- Improvement opportunities
- Specific recommendations
- Remediation resources
- Follow-up assessments

## Analytics and Reporting

Track assessment performance:
- Individual learner scores
- Item analysis (difficulty, discrimination)
- Pass rates
- Time to completion
- Common misconceptions
- Trends over time

## Quality Assurance

Regular assessment review:
- Medical content accuracy
- Question clarity
- Answer key validation
- Fairness evaluation
- Performance statistics
- Expert review

## Security and Integrity

- Secure question banks
- Randomization options
- Time limits
- Proctoring when required
- Academic integrity policies
- Plagiarism detection

## Accessibility

All assessments must:
- Provide reasonable accommodations
- Support screen readers
- Offer alternative formats
- Allow extended time when appropriate
- Use clear, readable fonts
- Ensure color contrast
